# Port Log - Sprint 1
 
## Sprint actual
Sprint 1
 
## Objetivo
Aplicar conocimientos de versionado, organización y análisis exploratorio
de datos con pandas sobre un dataset real de operaciones portuarias.
 
## Introducción y contexto
El Puerto Fluvial de Rosario es el principal punto de exportación de granos
y derivados de la Argentina. Su sistema de registro de movimientos fue
migrado desde un sistema heredado de los años 90, que acumuló
inconsistencias en fechas, matrículas de buques y valores numéricos fuera
de rango. En este sprint se analiza y depura el dataset del sistema
antiguo para poder incorporarlo al nuevo.
